A collection of academic, personal, and collaborative projects exploring different areas of computer science.

### ☁️ ASCEND — Azure Cloud Enrollment System

A cloud-deployed student enrollment platform that allows students to submit applications, upload documents, and track enrollment status while administrators manage application reviews.

**Highlights:** Cloud deployment, document storage, monitoring, autoscaling, and CI/CD.

`Python` `Flask` `Microsoft Azure` `Azure SQL` `Blob Storage` `GitHub Actions`

[Repository](https://github.com/renzzomontenegro/ascend) · [Live Application](https://ascend-app-dfhbhdfcddewgdda.eastasia-01.azurewebsites.net/) · [Demo Video](https://youtu.be/Ft73xUu7MQs)

### 🧠 Morphism — Taglish Grammar Correction

A Filipino-English code-switched grammar correction application developed as an NLP course project. It uses a fine-tuned language model to correct grammar, spelling, and punctuation while aiming to preserve conversational tone and meaning.

**Highlights:** LoRA fine-tuning, NLP pipeline, REST API, and web application integration.

`Python` `Mistral-7B` `LoRA` `Flask` `React` `Vite`

[Application Repository](https://github.com/renzzomontenegro/NLP-FINAL-PROJECT) · [Model Repository](https://github.com/renzzomontenegro/Taglish-Grammar-Correction-Model-Fine-tuned-Mistral-7b) · [Live Application](https://morphism-ebon.vercel.app/)

### 📐 3D Image Projection Using Linear Algebra

An interactive Python application demonstrating how 3D objects are transformed and projected into 2D wireframe representations using matrix operations and linear algebra.

**Highlights:** Rotation matrices, orthographic projection, vector transformations, and interactive visualization.

`Python` `NumPy` `Pygame` `Linear Algebra`

[Explore Repository](https://github.com/renzzomontenegro/3D-Image-Projection-Using-Linear-Algebra)
